# Fotografias da campanha

Coloque aqui as fotos reais (mesmos nomes, `.jpg` obrigatório e `.webp` recomendado):

| Arquivo | Uso | Proporção sugerida |
|---|---|---|
| `hero` | Primeira dobra — veículo em estúdio, fundo escuro, espaço negativo à esquerda | 16:9, 2400 px |
| `showroom-zero-km` | Grade do showroom (grande) | 16:10, 1800 px |
| `showroom-seminovo` | Grade do showroom (vertical) | 3:4, 1200 px |
| `showroom-detalhe` | Detalhe de carroceria/reflexo | 4:5, 1200 px |
| `showroom-panorama` | Pátio / linha de carros | 12:5, 2400 px |

Use fotos reais do estoque da Multi Car (ou banco de imagens licenciado). Enquanto um arquivo não existir,
o site mostra um fundo de estúdio neutro com o nome do arquivo pendente.
